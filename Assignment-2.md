Differentiate between Structured and Unstructured Datasets.

| **Structured Dataset**                                            | **Unstructured Dataset**                                                                              |
| ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1. Structured data is organized in a fixed format.                | 1. Unstructured data does not follow a fixed format.                                                  |
| 2. It is arranged in rows and columns.                            | 2. It is not arranged in a specific row-and-column format.                                            |
| 3. It is easy to store, manage, and analyze.                      | 3. It is more difficult to store, manage, and analyze.                                                |
| 4. It follows a predefined schema.                                | 4. It does not follow a predefined schema.                                                            |
| 5. It is usually stored in relational databases.                  | 5. It is commonly stored in files, data lakes, and NoSQL systems.                                     |
| 6. It can be easily searched using SQL.                           | 6. It often requires special tools and techniques for analysis.                                       |
| 7. Examples include names, ages, salaries, and employee records.  | 7. Examples include images, videos, audio files, emails, and social media posts.                      |
| 8. It is easier to process using traditional data analysis tools. | 8. It often requires advanced techniques like Natural Language Processing (NLP) and image processing. |
