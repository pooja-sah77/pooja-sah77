Short note of Normalization

Normalization is a data preprocessing technique used in Data Science and Analytics to bring numerical data into a common scale or range.
It helps prevent values with larger ranges from dominating values with smaller ranges.

Purpose of Normalization:
1. To bring data into a common scale.
2. To improve the performance of machine learning algorithms.
3. To reduce the effect of different measurement units.
4. To make data easier to compare and analyze.

Common Methods of Normalization:
1. Min-Max Normalization: Converts data into a fixed range, usually 0 to 1.
2. Z-Score Normalization: Transforms data based on its mean and standard deviation.
Example: If the ages of people range from 10 to 80, normalization can convert these values into a range between 0 and 1.

Normalization helps maintain consistency in a dataset.
It is useful when different features have different scales.
It helps algorithms such as K-Nearest Neighbors (KNN) and K-Means perform better.
It prevents features with large numerical values from having too much influence.
It makes numerical calculations more balanced and efficient.
