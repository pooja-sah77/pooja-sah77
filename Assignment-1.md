Differentiate between KDD (Knowledge Discovery in Databases) and Data Mining.

| **KDD (Knowledge Discovery in Databases)**                                       | **Data Mining**                                                         |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 1. KDD stands for Knowledge Discovery in Databases.                              | 1. Data Mining refers to extracting useful patterns from data.          |
| 2. It is the complete process of discovering knowledge from data.                | 2. It is one step of the KDD process.                                   |
| 3. It includes data selection, cleaning, transformation, mining, and evaluation. | 3. It focuses on finding hidden patterns and relationships in data.     |
| 4. Its main goal is to discover useful knowledge.                                | 4. Its main goal is to identify meaningful patterns from data.          |
| 5. It involves several steps to obtain useful knowledge.                         | 5. It uses techniques like classification, clustering, and association. |
| 6. It has a broader scope.                                                       | 6. It has a narrower scope compared to KDD.                             |
| 7. It evaluates and interprets the discovered knowledge.                         | 7. It extracts patterns from large datasets.                            |
