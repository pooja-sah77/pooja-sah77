SHORT NOTE ON Probability Density Function (PDF)

A Probability Density Function (PDF) is a mathematical function used in probability and statistics to describe the probability
distribution of a continuous random variable. It shows how the values of a variable are distributed over a range.

Important Points:
1. PDF is used for continuous random variables.
2. It describes the distribution of probability over different values.
3. The total area under the PDF curve is always equal to 1.
4. The PDF value is always non-negative (zero or positive).
5. The probability of a variable falling within a particular interval is calculated by finding the area under the curve.
Example: Height, weight, and temperature are examples of continuous variables that can be represented using a probability density function.

SHORT NOTE ON  Cumulative Distribution Function (CDF)

A **Cumulative Distribution Function (CDF)** is a mathematical function used in probability and statistics to calculate the probability 
that a random variable is less than or equal to a particular value.

**Important Points:**

1. CDF is used for both discrete and continuous random variables.
2. It shows the cumulative probability up to a given value.
3. Its value always lies between 0 and 1.
4. It never decreases as the value of the variable increases.
5. The CDF starts from 0 and approaches 1.

**Formula:**

\\[ F(x)=P(X\leq x) \\]

Where:

- \\(F(x)\\) = Cumulative Distribution Function
- \\(X\\) = Random variable
- \\(x\\) = Particular value

**Example:** If we want to find the probability that a student's marks are less than or equal to 50, we use the CDF.
